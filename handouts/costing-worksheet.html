8Three questions to answer before you report back

(a) Which line was biggest? Did it surprise you?

(b) Which single number are you least sure of? How much would the total move if it were half, or double?

(c) What does the patient pay that is not on this sheet? Think of drugs bought outside, tests sent out, travel, food, an attendant, days of lost work.

Question (b) is a one-way sensitivity analysis done by hand. Question (c) is the difference between the provider perspective and the abridged societal perspective the Indian Reference Case asks for.
